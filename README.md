# E-Games — Painel Administrativo

Sistema administrativo para organizar campeonato Free Fire 4x4.

## Acesso local
Usuário: admin
Senha: egames2026

Essas credenciais são apenas para demonstração em HTML/JavaScript local. Para publicação real, use autenticação com servidor/banco de dados.

## Regras do sistema
- O banco começa vazio.
- Nenhuma equipe fictícia é criada automaticamente.
- Apenas equipes aprovadas entram em Equipes e no chaveamento.
- Resultados são criados a partir das partidas registradas.
- Dados ficam no localStorage do navegador.
